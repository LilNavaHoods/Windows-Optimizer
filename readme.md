## 📌 Visão Geral (Versão 4.3 Final)

O **Windows Optimizer v4.3** é um script executável via Prompt de Comando (`.cmd`) projetado para automatizar tarefas de limpeza, otimização de sistema e instalação simplificada de utilitários no Windows.

---

## ⚙️ Funções Disponíveis na Versão 4.3

Abaixo estão todas as funcionalidades presentes na versão final:

### 🧹 1. Limpeza e Manutenção de Sistema
* **Limpeza de Arquivos Temporários**: Eliminação automática de dados acumulados em `%TEMP%`, `Temp` do sistema e `Prefetch`.
* **Limpeza de Cache e Rede**: Redefinição e limpeza da cache de DNS (`ipconfig /flushdns`), além de liberação e renovação de IP.
* **Ferramenta de Limpeza de Disco**: Chamada e execução otimizada da verificação do Windows (`cleanmgr`).
* **Verificação e Reparo de Arquivos**: Execução simplificada dos comandos `SFC /scannow` e verificações da imagem do sistema via `DISM`.

### 🚀 2. Otimizações de Desempenho
* **Ajustes de Serviços**: Desativação de rotinas de telemetria e serviços secundários para redução do consumo de memória RAM e CPU.
* **Plano de Energia**: Ativação rápida de perfil de desempenho máximo/alto desempenho no sistema.

### 📦 3. Instalação e Utilitários (MoreAPPs)
* **Instalação Simplificada de Programas**: Automação via `winget` e scripts para download e instalação rápida de bibliotecas (Runtimes Visual C++, DirectX) e softwares essenciais.

---

## 🛠️ Como Executar

1. Faça o download do arquivo `Windows_Optimizer_v4.3_MoreAPPs.cmd`.
2. Clique com o **botão direito** sobre o arquivo baixado.
3. Selecione a opção **"Executar como Administrador"**.
4. Navegue através das opções numéricas apresentadas no menu do terminal.
